# Abnormal-event-detection
Spatio-Temporal Autoencoder based abnormal event detection project using Python.
## Overview
This project focuses on detecting abnormal events in video surveillance data using deep learning techniques.

## Tools Used
- Python
- Machine Learning
- Data Preprocessing

## Description
The model analyzes temporal and spatial features from video frames to identify anomalies. The performance was evaluated and optimized to improve detection accuracy.

## Outcome
Successfully implemented anomaly detection model and analyzed performance metrics.
